## 如何使用

这些技能的安装方式由各自仓库决定，常见有：

- 作为 Claude Code / Codex 等工具的插件或技能目录安装；
- 直接把 `SKILL.md` 所在目录复制到用户级技能目录；
- 克隆仓库后按上游 README 的说明使用。

## 收录标准

- 有明确的仓库地址和 LICENSE。
- 仍在维护或仍有参考价值；上游已弃用的项目会在说明中标注。
- 同一仓库只收录一次，按主要用途归类。
