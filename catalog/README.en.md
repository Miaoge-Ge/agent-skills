## How to use

Each upstream repository defines its own installation method, commonly one of:

- install as a Claude Code / Codex plugin or skill directory;
- copy the directory containing `SKILL.md` into your user-level skills directory;
- clone the repository and follow its README.

Check the upstream README for exact commands, dependencies, and limitations. This catalog does not copy upstream code.

## Inclusion criteria

- A public repository and a LICENSE.
- Still maintained, or still useful; deprecated projects are marked on the category pages.
- One entry per repository, filed under its primary use.

## Licenses

Most projects use MIT / Apache-2.0 / BSD-3-Clause. `SoftwareCopyright-Skill` uses **AGPL-3.0**, a copyleft license; check compliance before modifying or redistributing it. License information was verified in November 2026 and follows each upstream repository thereafter.

## Maintenance

- When adding or removing an entry, update the category page, the counts on this page, and the counts in the two root READMEs.
- Each entry must include a skill name, repository link, one-line description, and license.
